# NPOI

NPOI 2.7.4 and its managed dependencies are taken from official NuGet packages. The package manifest records exact versions, frameworks, source URLs, package hashes, DLL hashes and licenses.

All DLLs are Editor-only with Auto Reference disabled and reference validation enabled. Only the Excel Localization editor and test assemblies explicitly reference NPOI.

System.Buffers, System.Memory and netstandard are provided by Unity 2022.3. Unused framework variants are omitted. BouncyCastle.Cryptography is pinned to 2.6.2 and SixLabors.ImageSharp to 2.1.11.

Original nuspec files, license texts and third-party notices are under Licenses. For packages without an included license text, the pinned official repository source is recorded in packages.json.
